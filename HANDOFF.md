# Продолжение разработки Gramm

- Проверенная сборка перед расширением настроек: коммит `242abc8`.
  [Артефакт Windows x64](https://github.com/zaanw/gramm/actions/runs/45856400851/artifacts/15138499480).
- Коммит этапа 1 `cf265ab` отправлен в `codex/setup`.
  [Windows x64 CI](https://github.com/zaanw/gramm/actions/runs/45878374756).
- Главное меню находится в `settings_gramm_hub.cpp`. Экран очереди и
  истории находится в `settings_gramm.cpp`. Состояние воспроизведения
  принадлежит штатному медиаплееру и привязано к аккаунту.
- Основные ссылки на документацию, исходники и релизы AyuGram собраны в
  [FEATURE_MATRIX.md](FEATURE_MATRIX.md). Для этапа 1 код AyuGram не переносился.
- После прохождения Windows CI для этапа 1 проверить восемь переходов,
  возврат, смену темы и масштаба, сохранение локального имени, повтор и
  очистку истории Music+. Затем перейти к General и Appearance+ по
  [DEVELOPMENT.md](DEVELOPMENT.md).
- Локальный этап 2 содержит настройки иконок Windows, видимость пунктов
  меню, поиск, регистрацию `tg://`, импорт и экспорт JSON и отключение
  хвостиков пузырей. Требуются компиляция и проверка каждого поведения.
- Profile+ расширен локальным Owner Gramm-бейджем (корона + логотип),
  произвольным локальным номером и коллекцией подарков с полями названия,
  паттерна и фона. Данные ограничены 32 подарками и не отправляются в API;
  нужны Windows CI и проверка сохранения после перезапуска.
- Для видимости между пользователями Gramm добавлен явный `GRAMM_PROFILE_V1`
  card: Copy в буфер → отправка пользователю → Import из буфера. Импорт
  сохраняет профиль по Telegram user ID и включает бейдж в профиле контакта.
  Произвольный серверный статус, Premium и Telegram-верификация не меняются.
