# AyuGram Desktop и Gramm

Статусы отражают этапы разработки для Windows x64. «Исходники» означает, что
изменение подготовлено. «Собрано» означает успешную компиляцию и упаковку
указанного коммита. Для проверки поведения нужен тест в запущенном клиенте.

## Источники

- Документация описывает выбор иконок, настройку меню, подтверждения,
  снимки сообщений и режим для демонстрации экрана.
  [AyuGram Desktop Features](https://github.com/AyuGram/AyuGramDocs/blob/main/desktop/features.md)
- В v6.2.4 изменили интерфейс настроек и добавили фильтры, перевод и
  настройку главного меню. В v6.7.8, среди прочего, добавили скругления,
  поиск в настройках, сохранение параметров снимка и фильтр искажённого текста.
  [История релизов](https://github.com/AyuGram/AyuGramDesktop/releases)
- Декларации настроек подтверждают точки конфигурации для шрифтов, аватаров,
  снимков сообщений, фильтров, источника перевода и режима демонстрации.
  [Исходный файл ayu_settings.h](https://github.com/AyuGram/AyuGramDesktop/blob/dev/Telegram/SourceFiles/ayu/ayu_settings.h)
- Исходники интерфейса AyuGram показывают отдельные страницы, общий
  конструктор настроек и опции оформления. Редактор снимка использует
  отдельный холст и повторный рендер для предпросмотра.
  [Меню AyuGram](https://github.com/AyuGram/AyuGramDesktop/blob/dev/Telegram/SourceFiles/ayu/ui/settings/settings_main.cpp) ·
  [Appearance](https://github.com/AyuGram/AyuGramDesktop/blob/dev/Telegram/SourceFiles/ayu/ui/settings/settings_appearance.cpp) ·
  [Message Shot](https://github.com/AyuGram/AyuGramDesktop/blob/dev/Telegram/SourceFiles/ayu/ui/boxes/message_shot_box.cpp)
- Навигация Gramm построена по предоставленному макету в штатных виджетах
  Telegram Desktop. На первом этапе исходники AyuGram использованы для
  исследования. Заимствований кода AyuGram на этом этапе нет.
  [GPL и уведомления](https://github.com/AyuGram/AyuGramDesktop/blob/dev/LEGAL)
